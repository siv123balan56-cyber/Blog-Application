# Full Stack Blog Application

## About Project
A Full Stack Blog Application that allows users to create, view, edit, delete, and search blog posts.

## Features
- User Registration
- User Login
- Secure Authentication
- Create Blog
- View Blogs
- Edit Blog
- Delete Blog
- Search Blogs
- User Dashboard
- User Profile
- Logout
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript
- Supabase

## Database
Supabase

Table Name: blogs

Fields:
- id
- user_id
- title
- content
- created_at
- updated_at

## How to Run
1. Download the project.
2. Open the project folder in VS Code.
3. Configure Supabase URL and Publishable Key in script.js.
4. Open index.html in a browser.
5. Register or login to use the application.

## Backend Setup
1. Create a Supabase project.
2. Create the blogs table.
3. Enable Row Level Security.
4. Configure database policies.
5. Connect Supabase with JavaScript.
